# Affordmed Campus Hiring Assessment

Repository for Affordmed Campus Hiring Evaluation.

## Repository Structure

### Stage 1
Backend implementation using Node.js.

Features:
- User Registration API
- Authentication
- Custom Logger Middleware
- Notification Priority Logic
- API Integration

Files:
- auth.js
- logger.js
- register.js
- index.js

### Stage 2
Frontend implementation using React.

Features:
- Display All Notifications
- Display Top 10 Priority Notifications
- Notification Type Filtering
- React Router Navigation
- API Integration using Axios

Pages:
- All Notifications
- Priority Notifications

## Technologies Used

- Node.js
- React.js
- Axios
- React Router DOM
- JavaScript
- Git & GitHub

## Run Stage 1

```bash
cd stage1
npm install
node index.js
